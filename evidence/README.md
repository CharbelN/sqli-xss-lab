# Evidence

Real, reproducible output captured against the authorized lab host on 2026-11-23.
Nothing here is hand-edited except redaction of noise; regenerate any of it with the
scripts in [`../scripts`](../scripts).

```
evidence/
├── crawl/
│   └── entrypoints.json        # scoped crawler output — the attack-surface inventory
├── sqlmap/
│   ├── manual_probe_*.json     # differential SQLi probe results (baseline vs payloads)
│   ├── sqlmap_comments_id.log  # full sqlmap run log (guardrailed, risk/level 2)
│   └── output/                 # sqlmap's own session/output tree (gitignored)
├── xss/
│   ├── stored_probe.json       # stored-XSS proof: canary stored unencoded
│   ├── probe_*.json            # reflected-XSS probes (show Request-Validation block)
│   ├── poc_render.html         # PoC: exact server bytes rendered as HTML (open in a browser)
│   ├── browser_comment_field_active_injections.jpg  # live page carrying other parties' payloads
│   └── site_vulnerability_notice.jpg                # site's own "vulnerable to SQLi/XSS" banner
├── agent/
│   └── run.json                # Phase-3 agent run log: scope, guardrails, hardened argv per target
└── zap/
    └── zap-report.{html,json}  # OWASP ZAP scan report (generated by scripts/run_zap.*)
```

## Notes

- **sqlmap output/** is listed in `.gitignore` — it can contain verbose session data.
  The curated `sqlmap_comments_id.log` is the human-readable record kept in the repo.
- **poc_render.html** contains only the operator's own benign proof markup (a colored
  heading) taken from the real server response — no third-party content, safe to open.
- Screenshots are from live browser testing; the comment pages are shared and
  "purged daily" per the site's own notice, so their exact contents vary over time.
